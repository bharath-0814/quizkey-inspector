🔎 QuizKey Inspector — Test Fixture Hub

Static demonstration fixtures for authorized assessment security auditing. Each fixture tests a specific client-side grading exposure pattern.

1. Randomized Option Order Vulnerable

Author state maintains original order with correctIndex: 1 (UDP), but client renders options shuffled as C. UDP. Verifies option text mapping overrides display index.

2. Author Response & Option IDs Vulnerable

Author grading uses correctOptionId: "opt_udp" mapped against DOM options containing data-option-id attributes.

3. Author Response Scoring Vulnerable

Each choice includes author grading points (score: 1 vs score: 0) leaked in client state.

4. Choices Flagged with isCorrect Vulnerable

Choice objects delivered to the browser contain embedded isCorrect: true flags.

5. External Answer Key Dictionary Vulnerable

Assessment configuration leaks an answerKey: { "1": "B" } dictionary mapping question IDs to answers.

6. Inline JavaScript Variable Vulnerable

Page script defines a global JavaScript array containing correctAnswer and correctIndex.

7. Embedded JSON Hydration State Vulnerable

A <script type="application/json"> element leaks question answer data in SSR/hydration state.

8. Network API Response Vulnerable

Questions fetched over XHR/fetch legitimately contain correctIndex: 1 in JSON payloads.

9. Browser Storage (localStorage) Vulnerable

Cached quiz state stored in localStorage contains answers.

10. Encoded HTML DOM Attribute Vulnerable

Hidden Base64 encoded payload in DOM attribute data-correct-answer.

11. Secure Server-Side Architecture Secure

Server retains grading keys and sends questions only. QuizKey Inspector reports 🟢 NO CLIENT-SIDE ANSWER KEY DETECTED.
